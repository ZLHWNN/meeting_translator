# ADR 002: Realtime Transcription Provider Adapter

## Status

Accepted for P2; exact SDK/model configuration must be verified before P3.

## Decision

The server owns an OpenAI Realtime transcription connection using `gpt-realtime-whisper` and a `type: "transcription"` session. It forwards 24 kHz PCM audio, manually commits segments generated by client VAD, maps interim transcription deltas by provider `item_id`, and maps completed transcription events to finalized source entries. Only finalized source text invokes the translation adapter.

## Context

The product requires interim source feedback, a stable finalized transcript, and a five-second translation target. The official API reference documents Realtime WebSocket communication, PCM input, append events, transcription deltas, completed events, and VAD.

## Consequences

- The client must produce the documented PCM format and deterministic segment commits.
- The server must handle asynchronous provider event ordering and provider error events.
- Transcription is treated as guidance, not an infallible representation of the audio.
- `gpt-realtime-whisper` is the selected streaming transcription model; translation model ID remains environment configuration and must be selected from current official documentation plus oracle testing.
